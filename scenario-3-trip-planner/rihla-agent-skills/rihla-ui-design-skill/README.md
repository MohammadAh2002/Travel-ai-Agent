# Rihla UI Design Skill

Copy the `travel-agent-ui-design` folder into the skills directory supported by your coding agent (for example `.agents/skills/`, if that is the discovery path configured for your tool).

The skill instructs the agent to inspect Rihla's actual frontend stack and API contracts before making changes. It focuses on a polished travel-planning workspace, itinerary-first UX, responsive layouts, accessibility, real interaction states, and preserving the existing approval flow.

Check your coding agent's documentation for its exact skill discovery directory.
